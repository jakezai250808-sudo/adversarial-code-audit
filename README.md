# adversarial-code-audit

> 多代理对抗式深度代码审计与自动修复流水线 —— 一个可直接给编码 Agent（Claude Code / Codex /
> ZCode 等任何读 SKILL.md 的运行时）使用的开源 Skill。

**一句话效果（实测）：**

> 七轮生产实战：多代理并行审计＋对抗复核＋自动修复闭环，累计确认 **232 个真实缺陷（高危 13）**；
> 单轮 **2.45～3 亿 token、2.3～7.5 小时**（两轮全量实测）扫完全量代码库，修复自动过测试门禁出草稿 PR。
>
> （内部生产仓库实测：服务端、移动端与 RPC 服务面；依赖支持子代理编排的 Agent 运行时。）

## 它是什么

把一次全量代码审计拆成六个阶段的多代理流水线：

1. **按功能域并行审计**——每单元限定文件清单与焦点，产出双侧证据（代码证据+语义证据）、
   可复算、且已自行试图推翻的发现；
2. **每条发现交独立复核员，其唯一任务是推翻它**——维持/推翻/修正三选一，修正（改定性、
   严重度、修法）本身就是独立思考的铁证；
3. **跨域去重**（同一根因常被接口两侧各报一次）；
4. **按域自动修复**——服从复核裁定而非原始描述，同根因全实例一次清；
5. **确定性门禁循环**——仓库自己的测试/编译/契约检查，逐字摘要，≤3 轮善后；
6. **三段式报告**（确认并修复 / 已推翻附理由 / 未覆盖附原因）+ 覆盖率账本 + 仓库外证据目录，
   以草稿 PR 交付。

另附：契约一致性专项（客户端×服务端）、线上真实数据对账专项（只读凭据 + 部署版本指纹）、
元审查（审审计：抽样独立重推演、锚点抽查、推翻率健康度）、隐私与凭据红线。

## 实测数字（已脱敏）

| 轮次 | 规模 | 确认发现 | token / 时长 |
| --- | --- | --- | --- |
| 服务端逻辑审计 | 10 功能域 | 37（high 3） | — |
| 客户端契约审计 ×2 | 17+8 单元 | 47（high 4） | — |
| 线上真实数据对账 | 8 单元（只读 key） | 13（high 1） | — |
| 全量补齐审计 | 14 单元（全局可审宇宙约 16% 起步；点名域此前已达 100%） | 81（high 2） | 3.0 亿 / 2.3h |
| 已合入 PR 复审 | 13 PR | 32（high 3） | — |
| RPC 接口面全量盘点 | 11 功能域 | 22（21 自动修复） | 2.45 亿 / 7.5h |

另有一次 7 域 70 端点的线上全接口普查：产出为已知症状逐项复核与新发现转跟进，未计入上表数字。

元审查抽样 29 条独立重推演：**零错判、平均严谨度 4.7/5、7 项可证伪预测全命中**。已知最弱
环节（severity 空确认、单样本线上证据、复核员过度保守）均已固化为 SKILL.md 内的硬规则。

方法论源自 2026 年多个生产仓库的七轮实战（后端服务、移动端、RPC 服务面），已去除全部
项目、仓库、平台与凭据细节。

## 安装与使用

不同运行时读取的技能目录不同，装错目录 Skill 不会被加载：

| 运行时 | 全局目录 | 仓库级目录 |
| --- | --- | --- |
| ZCode 等支持 `~/.agents` 约定的运行时 | `~/.agents/skills/` | `.agents/skills/` |
| Claude Code | `~/.claude/skills/` | `.claude/skills/` |
| Codex CLI | `~/.codex/skills/` | — |

```bash
git clone https://github.com/<you>/adversarial-code-audit <上表你所用运行时的目录>/adversarial-code-audit
# 后续更新：cd <该目录>/adversarial-code-audit && git pull
```

目录约定以你所用运行时的官方文档为准；装完对 Agent 说「用 adversarial-code-audit 审计 <范围>」验证能否被发现。

- 入口是 [SKILL.md](SKILL.md)（Agent Skills 标准格式，含 frontmatter）；需要把方法论落成
  一次可运行编排时，让 Agent 读 [references/orchestration-template.md](references/orchestration-template.md)。
- 对 Agent 说「用 adversarial-code-audit 审计 <范围>」即可；单会话 Agent 也有串行降级用法
  （见模板末节——对抗性来自角色隔离，不来自并行）。
- 上线自己的仓库前，把模板常量节的两条示例单元换成你的功能域切分（文件清单+焦点），基线
  SHA 记进常量，证据目录指向仓库外路径。
